
This is a Git Guide for Windows enviroment:

This document describes GIT for Windows instalation which will permit, using Windows in a Linux emulation enviroment in order to call and view GIT Commands:

1 Git installation:

https://git-scm.com/install/

https://git-scm.com/install/windows

![Git Setup](images/GIT SETUP.png)

Click here to download the latest (2.56.0(3)) x64 version of Git for Windows. This is the most recent maintained build. It was released on 2026-10-22.

2. Open .exe file and click next until the end.

3.You are readdy to start practicing Git.

4. As a starting point, create a Readme file or any txt file you want and save it into Desktop --- > GIT LAB Folder.

5. In GIT move GIT to the folder, as in the below image(Notice my directory path is different). Proceed as in the image so GIT is initialized. if you do a ls -a youll see a .git, that means git is tracking this folder.
6. Now you can start adding files to the working directory!!!!!
